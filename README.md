# HeliysStudio — бот + Mini App

Бот для нарезки фото на сториз и рамок для аватарок. Всё управление и покупки — внутри Telegram Mini App
(дизайн «Aurora Bento»: OLED-чёрный фон, аврора и бенто-плитки, анимированное обучение при первом входе, админ-панель для админа).

## Что умеет
- **Нарезка сториз** — 1–6 частей 1080×1920 (режимы «Заполнить» / «Вписать»), отправка файлами без сжатия.
- **37 рамок для аватарки** в 5 категориях: Модерн (неон, аврора, стекло, жидкость, голограмма, золото…), **Minecraft** (трава, незер, энд, алмазы — пиксельные блоки),
  Природа (**сакура**, осень, ромашки, зима, огонь, лавр), Космос (галактика, киберпанк, синтвейв, звёзды), Фан (корона, кошка, нимб, сердечки).
  Для «модерн»-рамок цвета подбираются из фото (6 палитр), тематические — со своими цветами. Результат — PNG 1024×1024 с прозрачным фоном.
  Фото можно загрузить в Mini App, взять текущую аватарку Telegram или просто отправить боту в чат.
- **Монетизация (Telegram Stars)**: 5 бесплатных генераций → 10 генераций за 15 ⭐ → Premium за 50 ⭐ (безлимит навсегда).
  Покупка только из Mini App (вкладка «Профиль» или окно при нулевом балансе).
- **Вкладки**: Главная (нарезка + рамка), Профиль (ID, дата первого запуска, аватарка, магазин), Админ (только для админов).
- **Админ-панель**: статистика, список запускавших бота и поиск, приветствие (с премиум-эмодзи),
  обязательная подписка на каналы, бан/разбан, выдача/снятие баланса и Premium, рассылка, цены и лимиты.

## Запуск
1. Токен и ID админа уже в `.env`. Чтобы Mini App открывался, нужен **публичный HTTPS-адрес** — впишите его в `WEBAPP_URL`.
2. Двойной клик по `start.bat` (или `python main.py`). Бот сам поставит кнопку «Открыть» в меню чата.

### Публичный адрес (выберите один способ)
- **Постоянно, Amvera**: загрузите папку проекта (есть `amvera.yaml`), в переменных задайте `BOT_TOKEN`, `ADMIN_IDS`,
  `DATA_DIR=/data`, `PORT=8080`, `WEBAPP_URL=https://<ваш-проект>.amvera.io`.
- **Быстрый тест с ПК** (без установки программ, Windows 10+ с OpenSSH):
  `ssh -R 80:localhost:8080 nokey@localhost.run` — в выводе будет `https://….lhr.life`; впишите его в `WEBAPP_URL`
  и перезапустите бота. Адрес меняется при каждом запуске туннеля.

### Настройка в @BotFather (по желанию)
`/mybots → бот → Bot Settings → Menu Button` — не нужно, кнопка ставится автоматически.
Для красивой ссылки: `/newapp` и укажите тот же `WEBAPP_URL`.

## Админ-панель
- Админы задаются в `.env`: `ADMIN_IDS=8717087613` (через запятую для нескольких).
- **Приветствие с премиум-эмодзи**: в разделе «Приветствие» нажмите «Прислать боту» и отправьте боту сообщение
  с эмодзи — оно сохранится вместе с ними. `{name}` в тексте заменится на имя пользователя.
  Команда `/emojiid` покажет теги `<tg-emoji>` для ручной вставки.
- **Обязательная подписка**: добавьте `@канал` (бот должен быть админом канала). Для приватного канала укажите ID `-100…` и ссылку-приглашение.

## Безопасность
- Mini App проверяет подпись `initData` (HMAC) на сервере, админ-эндпоинты доступны только `ADMIN_IDS`.
- Токен хранится в `.env` (в `.gitignore`). Токен попал в чат — при желании перевыпустите его в @BotFather (`/revoke`) и замените в `.env`.

## Структура
```
main.py            запуск: HTTP-сервер Mini App + long polling бота
app/               config, db (SQLite), imaging (Pillow), server (API), handlers (бот)
webapp/            index.html, app.css, app.js — Mini App без сборки
app/frames.py      все 37 рамок (Pillow)
tools/dev_server.py  локальный предпросмотр дизайна в браузере (без Telegram)
videos/storyframe-promo/  промо-ролик (HyperFrames): renders/video.mp4
```
